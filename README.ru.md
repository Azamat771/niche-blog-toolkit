# niche-blog-toolkit

> Самохостинговая одностраничная **контент-студия** для нишевых Instagram-блогеров.
> Курируемый банк идей со структурой хук/CTA · AI-генератор с живыми трендами · SMM- и UGC-агенты · Воркшит «Упаковка профиля».
> Чистый HTML/JS без сборки · мини Node-бэкенд · DeepSeek (LLM) + Tavily (web search). MIT.

**[🇬🇧 README in English](./README.md)**

## Что это

Большинство «AI-инструментов для контента» — универсальные SaaS «для любого блогера» и по сути обёртки над ChatGPT.
Эта тулза делает противоположную ставку: **один блогер, одна ниша, глубокая специализация**.

Ты заполняешь один `niche.json` (аудитория, тон, рубрики, палитра, дефолты упаковки) — и получаешь
mobile-first веб-приложение, где ты можешь:

- **Листать курируемый банк идей.** У каждой идеи готовая структура: *хук (первые 3 сек)* → *что показать* → *приём удержания* → *CTA* → *почему зайдёт* → бейджи целей (охваты / сохранения / вовлечение). Примеры идут с **154 идеями для ниши растений** и **30 для фитнеса**.
- **Генерить свежие идеи** в один тап. AI читает твою «упаковку профиля» + живые тренды ниши (через Tavily web search, кэш 12 ч) + текущий сезон + твои последние 8 заголовков (анти-повтор) и возвращает структурную идею.
- **Использовать SMM-агента** — 4 действия: подписи + хэштеги, контент-план на неделю, адаптация поста под Telegram/VK, идеи Stories-активностей.
- **Использовать UGC-агента** — 4 действия: UGC-сценарий (хук → тело → CTA + раскадровка + текст под озвучку), питч-письмо бренду, идеи по категории товара, одностраничный медиа-кит с ценами.
- **Заполнить «Упаковку профиля»** (позиционирование, имя для поиска, шапка, мультиссылка, актуальное, закреп, визуал, голос). Эти тексты становятся контекстом, который читают все AI-фичи.

Данные живут в `localStorage` браузера. Бэкенд видит только то, что ты сама отправляешь AI-кнопками.

## Стек

- **Фронт** — один `index.html` (~140 КБ), без сборки и фреймворков. Mobile-first, sticky-вкладки, тап-зоны ≥44 px, iOS не зумит при фокусе.
- **Бэк** — Node-сервер на `http`/`https`, ~500 строк, **zero-dependency**.
  - `POST /api/generate` — структурная идея (DeepSeek JSON-mode)
  - `POST /api/agent` — действия SMM/UGC (DeepSeek markdown)
  - `GET  /api/health` — статус + расход + возраст кэша трендов
- **LLM** — [DeepSeek](https://platform.deepseek.com) (OpenAI-compatible, ~$0.0005 за вызов).
- **Тренды** — [Tavily](https://app.tavily.com) (1000 бесплатных запросов/мес). Кэш 12 ч → ~60 вызовов/мес.
- **Защита** — CORS + shared-токен + rate-limit по IP + дневной USD-cap → 429.

## Быстрый старт

```bash
# 1. Клонируем
git clone https://github.com/Azamat771/niche-blog-toolkit
cd niche-blog-toolkit

# 2. Конфиг бэкенда
cp backend/.env.example backend/.env
# редактируем backend/.env — вписываем DEEPSEEK_API_KEY и (опционально) TAVILY_API_KEY

# 3. Рендерим демо (plants — 154 идеи) в frontend/dist/index.html
node scripts/apply-niche.js examples/plants

# 4. Запускаем бэкенд
cd backend && node server.js
# Слушает на 127.0.0.1:3007

# 5. Открываем фронт (frontend/dist/index.html — обычная статика)
# В продакшене — за nginx с проксированием /api/ на 127.0.0.1:3007.
```

## Сделать свою нишу

```bash
# 1. Копируем fitness-пример и правим под себя
cp -r examples/fitness examples/my-niche
$EDITOR examples/my-niche/niche.json
#   → задай title, brand, niche, audience, tone, rubrics, trendQuery, colors,
#     дефолтные тексты packaging

# 2. Сгенерим стартовый банк идей (запишет seed-ideas.json)
node scripts/seed-ideas.js examples/my-niche --count=100

# 3. Рендерим и можно деплоить
node scripts/apply-niche.js examples/my-niche
# → frontend/dist/index.html готов к scp куда угодно
```

Стоимость шага 2: ~$0.02 в токенах DeepSeek на 100 идей.

## Как устроена структура идеи

Каждая идея — курируемая или сгенерированная — заточена под сигналы охвата Instagram (репосты в личку, сохранения, watch time):

| Поле | На что отвечает | Зачем |
|---|---|---|
| `hook` | Что дословно сказать/показать в **первые 3 секунды** | 50% уходят за первые 3 с. Хук — главное поле. |
| `shoot` | Что снять / показать по шагам | Убирает «а что вообще снимать?» |
| `retention` | Приём удержания (открытая петля, счётчик, «жди до конца») | Watch time — топ-сигнал алгоритма 2025–2026 |
| `cta` | Сохрани / отправь другу / напиши в комменты | Репосты в личку — главный множитель охвата |
| `why` | Почему эта идея сработает на алгоритме и аудитории | Учит, а не просто говорит «сделай это» |
| `viral` | Теги-цели: `reach` / `saves` / `engagement` | Видны как бейджи на карточках |

## Шпаргалка по `niche.json`

| Ключ | Описание |
|---|---|
| `name` | slug для ключей `localStorage` и CLI |
| `title` / `subtitle` / `emoji` | заголовок страницы, шапка, эмодзи-маскот |
| `brand` | дефолтный Instagram-хэндл в плашке шапки (например `@my_blog`) |
| `niche` | вшивается в каждый AI-промпт (например `"домашние тренировки"`) |
| `audience` | вшивается в каждый AI-промпт |
| `tone` | правила голоса (например `"тёплый, на ты, без жаргона"`) |
| `rubrics[]` | чипы-фильтры и теги рубрик. Рекомендую 10–14. Формат: `{id,name,emoji,color}` |
| `trendQuery` | шаблон запроса в Tavily. Плейсхолдеры `{month}`, `{year}`, `{niche}`. |
| `colors` | `primary`, `primaryDark`, `accent`, `bg` (hex) — перекрашивает весь UI |
| `packaging.*` | дефолтные тексты для вкладки «Упаковка профиля» |

Полная схема — [`config/niche.schema.json`](./config/niche.schema.json).
